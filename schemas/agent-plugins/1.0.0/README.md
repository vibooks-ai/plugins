# Agent Plugins 1.0.0 Schemas

These files are byte-for-byte copies of the canonical schemas published at:

- `https://agent-plugins.org/schemas/1.0.0/plugin.schema.json`
- `https://agent-plugins.org/schemas/1.0.0/mcp.schema.json`

Keep them pinned to the specification version declared by root `plugin.json`
and `mcp.json`. Do not silently replace a published schema with content from a
different specification version.
