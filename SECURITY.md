# Security Policy

## Reporting A Vulnerability

Do not open a public issue for a suspected vulnerability involving credentials,
local bookkeeping data, write authorization, plugin installation, or Vibooks API
access. Report it through the private contact path at
https://vibooks.ai/support/ and include the affected plugin version, agent
client, operating system, reproduction steps, and expected impact.

Block Software Inc. will acknowledge a complete report and coordinate any
necessary remediation and disclosure. Do not include real customer bookkeeping
data, access tokens, license credentials, or private source documents in the
report.

## Supported Versions

Security fixes are issued for the latest published Vibooks Agent Plugin version.
Users should update through the marketplace from which they installed the
plugin and start a new agent task after an update.
